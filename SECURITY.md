# Security policy

MUSE-IDR is research software and does not process secrets by design. Do not
commit access tokens, private datasets, credentials, or personally identifying
information.

For a security-sensitive report, contact the repository owner privately through
the GitHub account listed in `CITATION.cff` rather than opening a public issue.
Supported fixes target the latest `main` branch. The immutable paper tag remains
available for reproducibility and will not be rewritten.
