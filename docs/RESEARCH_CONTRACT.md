# MUSE-IDR 研究合同

版本：0.2

状态：根据“CAID1训练、CAID2/3测试”的研究目标于2026-08-21重新冻结

目的：防止标签定义漂移、CAID 信息泄漏和事后选择指标。

## 1. 唯一任务定义

输入是一条氨基酸序列 `x = (x1, ..., xL)`。

模型只输出：

```text
p = (p1, ..., pL),  pi ∈ [0, 1]
```

`pi` 是第 `i` 个残基属于“实验支持的经典固有无序区域”的概率。模型只有一个通用残基级输出头。

本项目中的“强固有无序”只表示“不引入 SoftDis 概念”，不是新的生物学类别。论文和代码统一使用“经典固有无序”或“实验支持的固有无序”。

## 2. 明确禁止的任务变化

- 不建立 SoftDis 标签、损失函数或输出头。
- 不建立 NOX 头、PDB 头或数据集专用输出头。
- 不根据蛋白质来源切换不同预测器。
- 不把 AlphaFold pLDDT、其他预测器输出或 CAID2/3 标签作为监督信号。
- 不把未标注残基自动当成有序负样本。

NOX、PDB 只能作为同一个通用预测向量上的不同评测掩码；它们不是模型的两个任务。

## 3. 训练标签原则

### 3.1 正样本

正式正样本来自 DisProt 等数据库中有直接实验依据的经典无序残基。每条记录保留证据类型、数据库版本、下载日期和原始 accession。

以下信息不能单独构成训练正标签：

- X-ray 结构中的缺失电子密度；
- 高 B-factor；
- AlphaFold 低 pLDDT；
- SoftDis 标签；
- 任意计算预测器的输出。

### 3.2 负样本

负样本优先来自有可靠实验结构覆盖的 PDB 残基，并保存结构质量、链映射和覆盖证据。存在标签冲突或证据不足的残基标记为 unknown，并在损失和评测中屏蔽。

### 3.3 标签取值

- `1`：实验支持的经典无序残基；
- `0`：高置信实验结构支持的有序残基；
- `-1`：未知、冲突或不允许监督的残基。

只有 `0/1` 残基进入训练损失和内部指标。

## 4. CAID历史训练与硬隔离规则

CAID1属于较早公开的历史数据，可作为训练候选，但不再作为本实验系列的外部测试集。CAID1残基必须按第3节统一转换为`1/0/-1`，并通过CAID2/3的标识符、精确序列和同源排除后，才能进入内部训练/验证划分。CAID1的NOX/PDB概念不得变成数据集专用输出头。

CAID2、CAID3属于外部测试材料，禁止用于：

- 梯度训练或伪标签训练；
- 验证、早停和阈值选择；
- 架构、特征、损失权重和超参数选择；
- 选择随机种子、折数、检查点或集成权重；
- 归一化统计量和校准参数拟合；
- 根据CAID2/3结果决定保留哪个消融版本。

在构建训练/验证数据时，必须删除：

1. 与CAID2/3序列完全相同的记录；
2. 与CAID2/3具有相同accession及可映射isoform的记录；
3. 与CAID2/3序列相似度大于30%且双向覆盖度达到80%的同源序列。

具体隔离清单必须保存序列哈希、accession、数据集版本和同源搜索结果。阈值实现和边界情况将在数据步骤中固化并测试。

## 5. 模型选择与评价指标

### 5.1 首要指标

首要指标是内部无泄漏验证集上、所有已知标签残基汇总计算的 micro ROC-AUC。

选择模型时只比较预先声明的首要指标。ROC-AUC不依赖分类阈值，因此不能为提升首要指标而在CAID2/3上调阈值。

### 5.2 辅助指标

以下指标用于解释模型行为，不取代首要指标：

- PR-AUC；
- F1、MCC和balanced accuracy；
- 每条蛋白质AUC的宏平均；
- 区域级重叠和边界误差；
- 按序列长度、无序比例和物种分层的AUC。

### 5.3 最终外部测试

首次查看正式CAID2/3结果前，必须冻结：

- Git提交；
- 数据与划分哈希；
- 模型配置；
- 检查点选择规则；
- 集成成员和集成方式；
- 推理窗口及重叠融合方式。

CAID2/3的NOX/PDB等结果可以分别报告，但所有结果必须来自同一个通用IDR输出。

## 6. 内部数据划分

- 默认采用按序列同源簇分组的5折交叉验证，而不是随机按残基切分。
- 同一蛋白、isoform、近同源序列不能跨训练折和验证折。
- 所有数据清洗和特征统计只在对应训练折拟合。
- 默认随机种子为 `17、29、43`；如需增减，必须在查看CAID结果前决定。

## 7. 可复现性要求

每次正式实验至少记录：

- 实验ID和UTC时间；
- Git提交哈希及工作区是否干净；
- Python、PyTorch、CUDA、驱动和GPU型号；
- 完整配置文件及其SHA-256；
- 原始数据版本、下载日期和文件SHA-256；
- CAID2/3隔离清单与划分文件SHA-256；
- 随机种子、训练日志、最佳检查点和选择原因；
- 验证集逐残基预测，便于重新计算指标。

## 8. 可调与不可调边界

不可调：任务定义、单输出约束、CAID2/3隔离、首要指标和未知标签屏蔽规则。

仅可通过不含CAID2/3的内部验证调整：LoRA秩与目标层、多尺度卷积、特征分支、损失权重、学习率、正则化、窗口融合、随机种子数量和集成方式。

本合同若必须修改，需要新版本、书面原因和新的实验系列；不能静默覆盖旧规则。
