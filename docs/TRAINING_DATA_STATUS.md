# 训练数据构建状态

## 历史时间截断

CAID2/3是外部测试，因此当前训练正标签固定使用CAID2之前的DisProt `2018_11`快照。该快照同时包含CAID1历史增量和更早的DisProt记录。当前阶段不读取2023、2025或2026版DisProt注释来生成训练标签，以免把CAID2/3之后才公开的知识带回训练集。

## 标签生成规则

每个残基只允许三种状态：

- `1`：由预先列出的实验方法支持经典无序；
- `0`：本步骤不产生，后续只能由可靠PDB坐标覆盖产生；
- `-1`：未知，训练损失屏蔽。

旧版DisProt共有37种结构无序证据名称。配置显式允许35种实验方法；`Missing electron density`和`High relative B-factor`不能单独产生正标签。若遇到配置未分类的新证据，构建器直接报错，不能默认接收。

未标注位置、缺失电子密度位置和高B-factor位置都保持`-1`。当同一残基同时具有允许证据和排除证据时，允许的直接实验正证据优先，标签为`1`。

CAID2/3无标签哨兵发现7条历史候选存在直接泄漏：6条通过UniProt accession命中，1条通过完全相同序列命中。完全相同序列命中为历史`DP00080`与CAID2目标`DP03431`；两者ID不同，因此只有序列哈希层能够发现。

## PDB可靠负标签

负标签只使用DisProt `2018_11`中保留记录已经引用的历史PDB编号。旧交叉引用规范化后得到850个合法PDB编号；3个无法解析的旧值被记录并排除。PDBe元数据确认所有可用条目的发布日期都不晚于2018-11-30。

质量过滤规则：

- X-ray分辨率不大于3.0 Å；
- cryo-EM分辨率不大于4.0 Å；
- NMR允许无分辨率值；
- 其他实验方法排除。

850个条目中有756个通过质量过滤。SIFTS批量文件只读取`observed segments`，不使用未观测残基。映射必须同时满足完全相同的UniProt accession和完全相同的候选序列；不把isoform自动折叠到主accession。

当前版DisProt `2026_06`在这里只读取accession和sequence，用于证明当前SIFTS坐标与2018候选序列完全一致。代码禁止从该文件读取regions或标签，因此不会把未来注释带回训练集。

为避免把结合后折叠的IDR误标成有序，以下位置不能产生负标签：

- 任意DisProt Disorder区域；
- Molten globule和Pre-molten globule区域；
- 上述区域边界两侧各5个残基；
- 已有正标签的残基。
